이 블로그는 별도의 회원가입·로그인 기능이 없으며, 방문자가 직접 입력하는 개인정보를 수집하지 않습니다(댓글 작성 시는 예외이며 아래에서 별도로 안내합니다). 다만 아래 서비스를 통해 일부 정보가 자동으로 수집됩니다.

## 수집하는 정보

- **Google 애널리틱스(GA4)**: 방문 페이지, 접속 기기·브라우저 정보, 대략적인 접속 지역(IP 기반)을 쿠키를 통해 수집합니다.
- **Google 애드센스**: 광고 게재 및 맞춤형 광고 제공을 위해 쿠키로 방문 기록을 수집할 수 있습니다.
- **Cloudflare(CDN·보안)**: 이 블로그는 Cloudflare를 통해 서비스되며, 접속 시 IP 주소 등 연결 정보가 캐싱과 보안(DDoS 방어 등) 목적으로 Cloudflare에 의해 처리됩니다.
- **Giscus 댓글(GitHub 연동)**: 댓글 기능은 GitHub Discussions 기반 서비스인 Giscus를 사용합니다. 댓글을 작성하려면 GitHub 계정으로 로그인해야 하며, 작성한 댓글과 GitHub 프로필 정보(사용자명, 프로필 이미지)는 이 블로그가 아니라 GitHub 저장소의 Discussions에 공개적으로 저장됩니다. 댓글을 작성하지 않으면 이 정보는 수집되지 않습니다.

## 수집 목적

- 방문 통계 분석 및 콘텐츠 개선
- 광고 게재 및 수익 창출
- 사이트 성능 개선 및 보안(DDoS 등 악성 트래픽 방어)

## 제3자 제공

수집된 정보는 Google과 Cloudflare가 처리하며, 이 블로그 운영자가 별도로 저장하거나 제3자에게 제공하지 않습니다. 각 서비스의 데이터 처리 방식은 아래 문서를 참고하세요.

- [Google 개인정보처리방침](https://policies.google.com/privacy)
- [Google 광고 관련 개인정보처리방침](https://policies.google.com/technologies/ads)
- [Cloudflare 개인정보처리방침](https://www.cloudflare.com/privacypolicy/)
- [GitHub 개인정보처리방침](https://docs.github.com/ko/site-policy/privacy-policies/github-privacy-statement)

## 쿠키 거부 방법

브라우저 설정에서 쿠키를 차단하거나 삭제할 수 있으며, [Google 광고 설정](https://adssettings.google.com/)에서 맞춤형 광고 수신을 거부할 수 있습니다.
